# Support

- **Documentation**: start with [`docs/index.md`](docs/index.md) and the
  [troubleshooting guide](docs/troubleshooting.md).
- **Bugs and feature requests**: open an issue using the matching issue form.
  Include toolkit version, Python version, OS, and a redacted reproduction -
  never include credentials or real customer data.
- **Questions**: open an issue with the `documentation` form if the docs did
  not answer it; that doubles as a docs bug report.
- **Security issues**: never a public issue - see [SECURITY.md](SECURITY.md).
- **Commercial support for ALL WR itself** (the platform, your tenant, your
  data): contact Wealthreader through your usual ALL WR support channel;
  this repository only covers the open-source toolkit.

This is an open-source project: response times are best-effort (see
`MAINTAINERS.md`).
