# ALL WR Toolkit

Open-source migration, integration and automation tools for
[ALL WR](https://www.allwr.io) — a CLI, a typed API client, a connector SDK
and an MCP server.

- **Migrate**: bring your data from Asana or Freshdesk into ALL WR with a
  curated, plan-driven, resumable and idempotent migration.
- **Integrate**: reuse the typed ALL WR API client in your own tooling.
- **Automate**: let AI agents inspect and operate migrations safely through
  the MCP server (writes are opt-in on the server, never by the agent).

Start with the [quickstart](quickstart.md). Safety principles are summarized
in [security](security.md); they are not optional and every contribution must
preserve them.
